A visual design system in plain HTML and CSS. Cool neutrals, thin lines, a mono voice for data and one orange signal for the thing that matters.

Use it for interfaces, slides, email and images. Link two stylesheets and build with native HTML. No framework, no build step.

Get started See the foundations

/01 · What it is

A small set of decisions. Made once.

Every value has a job. Colour, type, space and shape are tokens. The basic elements are native HTML styled by those tokens. You decide less and ship a consistent result.

  1. 01
    Colour

    Eight cool neutrals, two surfaces, one signal.

  2. 02
    Type

    A sans for text. A mono for labels and numbers.

  3. 03
    Space

    Four steps: 8, 16, 32, 64. Each one has a job.

  4. 04
    Shape

    Three radii and one line weight: 1px.

  5. 05
    Elements

    Buttons, chips, fields, tables, panels, disclosures.

  6. 06
    Manual

    Use and don't-use rules that people and LLMs apply literally.

/02 · Where it goes

One look. Every surface.

The same tokens drive a dashboard, a deck, a newsletter and an article image. A reader recognises the voice before they read a word.

  • Interfaces

    Dashboards and tools

    Dense data in grey cells. The signal marks only the exception.

    ↘ See an example
  • Slides

    Decks and talks

    One idea per slide. Display type, a thin rule, generous space.

  • Email

    Newsletters and notices

    Two surfaces and one column survive every mail client.

  • Images

    Covers and illustrations

    Line, grid and a single warm mark, at any ratio.

/03 · Principles

Restraint is the feature.

  • One signal

    Orange marks the one thing that matters. Never more than 5% of the area.

  • Aa01

    Two voices

    Sans speaks the text. Mono speaks for the instrument: labels, numbers, dates.

  • Two surfaces

    Canvas and panel. A third level is a line, not another box.

  • One line weight

    Every border and divider is 1px. No shadows at rest.

  • <button>

    Native first

    Real tables, real checkboxes, real buttons. Accessible by default.

  • 0 deps

    No build

    Two stylesheets and custom properties. It works from a file on disk.

/05 · Get started

From file to page in five steps.

No package to install. Copy the src/ folder, link it and write HTML.

  1. Fonts

    Load Geist and Geist Mono.

  2. Tokens

    Link tokens.css.

  3. Elements

    Link elements.css.

  4. Build

    Native HTML with eis- classes. Layout CSS only.

  5. Check

    Run the checklist in the manual.

<!-- 1 · fonts -->
<link href="https://fonts.googleapis.com/css2?family=Geist:wght@300;400;500;600&family=Geist+Mono:wght@400;500&display=swap" rel="stylesheet">

<!-- 2 · 3 · the system -->
<link rel="stylesheet" href="src/css/tokens.css">
<link rel="stylesheet" href="src/css/elements.css">

<!-- 4 · build -->
<section class="eis-panel">
  <button class="eis-button eis-button--primary">Save</button>
  <span class="eis-chip eis-chip--signal">Overdue</span>
</section>
