04Space

Four values, each double the previous. They cover margin, padding, gap and offsets. Each one has a place, so it isn't picked at random.

  1. --space-1008px

    Inside a component: icon to label, tag padding.

  2. --space-20016px

    Between siblings: rows, list items, panel padding.

  3. --space-30032px

    Between blocks: panels, groups.

  4. --space-40064px

    Between sections and page gutters.

06Motifs

Built only from the tokens above. They come from the Teenage Engineering references: panel silkscreen, key matrices, hatched bands.

  • Block label

    Solid rectangle, knocked-out mono text. For graphic pieces (posters, slides, covers). In UI, use a chip.

  • Hatch

    Diagonal line at 135°. Marks what is not yours: personal blocks, unavailable.

  • Cell matrix

    Data as a grid of equal squares, like keys on a device.

  • Hairline

    Separate with a 1px line before reaching for a box.

07Rules

Budgets, not adjectives. The full list lives in docs/visual-guidance/visual-guidance.md.

  • Signal ≤ 5% of the area

    It marks a state, never decorates. One signal per piece.

  • Two surface levels

    Canvas and panel. A third level means the layout needs a line, not a box.

  • Mono for numbers and labels

    Sans for text. Labels are always uppercase and tracked.

  • No shadow, gradient or glow

    Depth comes from tone and hairlines.

  • Data in grey; signal for the exception

    Normal values never get colour.

  • Variants change colour only

    Never structure, size, radius or behaviour.
