01Buttons

A button acts. Rectangle, small radius, uppercase mono. Use <button> for actions and <a> styled as a button only for navigation.

Open report →

.eis-button (white) + --black · --ghost · --accent. Variants change colour only. One --black per view; --accent only for the action that is itself the accent (record, go live).

02Chips

A chip describes a state. Pill shape and sentence case, so it can't be mistaken for a button. Default cursor and no hover.

Accepted Maybe Organizer Conflict Cancelled
On track Urgent PLT-204 Billing

.eis-chip + --outline · --solid · --accent · --hatch · --dot. Hatch marks what no longer counts (cancelled, blocked). Accent is the only chip with colour.
